# CareLoop演示指南

## 演示前

打开首页，点击页脚“重置演示”并确认，恢复12份初始模拟记录。初始状态为11份已提交、7份已复核、3份待复核、1份待补充、1份草稿。

## 从一份记录看完整流程

### 患者填写

- 在顶部切换“患者视角”，或在项目人员侧栏进入“患者填写体验”。
- 默认使用演示参与编号P-013。
- 可点击“试试矛盾记录”，系统填入“尚未使用”但使用次数和体验评分非空的例子。
- 勾选参与说明后提交，查看检查结果。
- 点击“返回核对”可继续修改；点击“确认提交模拟记录”会保留原文并生成待复核记录。
- 再用同一编号和同一轮次提交时，启用的重复规则会阻止新增，并提示已有记录。

### 人工复核

- 点击提交成功弹窗的“去工作台复核”。
- 打开最新记录，查看原文、填写者、使用情况和待确认事项。
- 未填写处理意见时不能完成操作。
- 输入演示意见，再选择完成复核或请求补充。原文不被改写，历史记录追加。
- 完成复核不会消除尚未解释的规则提示，也不会改变酬谢状态。

### 企业交付

- 顶部切换“企业视角”，只显示企业报告和项目说明入口。
- 报告分开展示已提交、已复核以及有操作体验评分的记录数量。
- 草稿、待补充与待复核记录不进入体验评分分布。
- 点击下载得到本地TXT；打印按钮调用浏览器打印，可选择保存PDF。
- 这些汇总是对虚构样本的演示，不可作为真实产品效果或订单证明。

### 酬谢台账

- 切回项目人员，进入酬谢台账。
- 选择一笔未发放记录，确认“模拟登记”。
- 只有台账发放状态发生变化，不触发实际付款，也不改动复核状态。
- 已发放条目不再提供重复登记入口。

## 其他可体验项

- 搜索P-008，查看型号不清楚的记录。
- 搜索P-002，查看填写时间较短的提示。
- 在数据质控页切换规则，观察待确认标签更新。
- 记录导出跟随当前搜索和筛选；CSV含明确的虚构模拟标记。
- 保存患者填写草稿，刷新后进入患者页可恢复。
- 浏览器缩窄至手机宽度后，导航折叠为顶部菜单。

## 表述边界

可以说“演示了一个完整的记录处理流程”。不能说“已上线医院”“已经获得患者授权”“AI能识别所有虚假填写”“已发生真实支付”或“已获得企业订单”。
